About NetraaMart

NetraaMart is a coursework e-commerce marketplace project. This public website is a front-end demo (browse, cart, login UI) hosted on GitHub Pages.

The full Java source (servlets, JSP, H2, admin, chatbot) is in the GitHub repository.

  • Browse & search products
  • Add to cart (saved in your browser)
  • Demo login / register screens
  • Full backend code on GitHub for evaluation
